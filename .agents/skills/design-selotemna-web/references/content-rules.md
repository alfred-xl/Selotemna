# Selotemna Content Rules

## Voice

Write in clear, confident Nigerian English. Keep the tone professional, direct, helpful, calm, and specific. Prefer useful next steps over exaggerated luxury language.

## Division terminology

Use these primary division names exactly:

1. Real Estate Development
2. Engineering & Construction

Land and property opportunities belong under Real Estate Development. Do not present land sales, house sales, Property Management, or Construction as equal homepage divisions.

Property Management may be described only as a possible supporting service until its scope and placement are confirmed.

## Message hierarchy

Public pages answer:

1. What is this?
2. Which division or content type does it belong to?
3. Who is it for?
4. What verified information supports the decision?
5. What can the visitor do next?

The homepage provides a concise overview. Detailed content belongs on the appropriate division, project, inspection, FAQ, or contact page.

## Safe language

- Explore Real Estate Development opportunities.
- Explore verified projects.
- Contact the team for current availability.
- Request an inspection.
- Payment arrangements vary by opportunity.
- Documentation varies by property and location.
- A representative will contact you with the next step.

## Prohibited claims

Do not write or imply:

- guaranteed returns or appreciation;
- guaranteed titles or documentation;
- “100% verified,” “best,” “number one,” or “most trusted” without evidence;
- unverified years, statistics, awards, licences, certifications, partners, or testimonials;
- automatic inspection confirmation;
- unverified payment plans;
- virtual inspection, remote payment, or specialist legal support unless confirmed;
- unverified locations, amenities, infrastructure, landmarks, plot counts, fees, completion dates, or project statuses.

## Project status

Use only these public status labels:

- Ongoing Projects
- Completed Projects
- Upcoming Projects

Apply a status only when confirmed. Do not classify Omu Creek until its status is supplied.

## Demo content

Temporary project data may be used only for development and layout testing. It must be removed in production through the application environment and clearly identified as layout content in development.

Never present temporary content as verified Selotemna work. Exclude it from public metadata, SEO, structured data, sitemaps, analytics, statistics, case studies, and proof claims.

## Public production language

Never expose planning fields, media-production notes, approval status, upload requests, or “coming soon” language. If media is missing, adjust the layout or use a silent decorative branded surface.

## Omu Creek

Preserve exactly:

- Land allocation
- Lagos State Government Allocation
- ₦50,000 per sqm
- 300 sqm: ₦15,000,000
- 500 sqm: ₦25,000,000
- 1,000 sqm: ₦50,000,000
- Prices exclude applicable taxes.
- Availability and property information are subject to confirmation.

Use references/faq-content.md for the additional approved Omu Creek location, title claims, payment terms, charges, documentation, infrastructure, allocation, construction, default, resale, and refund content. Do not add facts beyond the approved source.

## Inspection language

Preferred labels include Book an Inspection, Request an Inspection, and Request an Omu Creek Inspection.

Submission language must state or imply a request only. Do not use “Inspection confirmed” unless a future system genuinely confirms appointments.

## FAQ boundary

The approved Omu Creek FAQ source is recorded in references/faq-content.md. Use only questions 1, 4, 5, and 6 on the homepage. The dedicated FAQ page contains the complete 15-item set.

## SEO

- Use the two-division terminology.
- Use verified project statuses and content only.
- Mention operating locations only when confirmed.
- Avoid keyword stuffing.
- Add structured data only when the data supports it accurately.
- Do not fabricate review, offer, product, property, or project schema.
