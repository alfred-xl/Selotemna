# Selotemna Content Rules

## Voice

Write in clear, confident Nigerian English. Keep the tone professional, direct, helpful, calm, and specific. Prefer useful next steps over exaggerated luxury language.

## Message hierarchy

Public pages answer:

1. What is this?
2. Who is it for?
3. What verified information supports the decision?
4. What can the visitor do next?

## Safe language

- Explore available property opportunities.
- Contact the team for current availability.
- Request an inspection.
- Payment arrangements vary by property.
- Documentation varies by property and location.
- Buyers should complete appropriate independent legal and professional due diligence.
- A representative will contact you with the next step.

## Prohibited claims

Do not write or imply:

- guaranteed returns or appreciation;
- guaranteed titles or documentation;
- “100% verified,” “best,” “number one,” or “most trusted” without evidence;
- unverified years, statistics, awards, licences, certifications, partners, or testimonials;
- automatic inspection confirmation;
- unverified payment plans;
- virtual inspection, remote payment, or specialist diaspora legal support unless confirmed;
- unverified locations, amenities, infrastructure, landmarks, plot counts, fees, or completion dates.

## Public production language

Never expose bracketed planning fields, media-production notes, approval status, upload requests, or “coming soon” language. If media is missing, adjust the layout or use a silent decorative branded surface.

## Property copy

Use verified information in this order:

1. Name
2. Type
3. Location, only when verified
4. Price or rate
5. Dimensions or options
6. Description
7. Documentation
8. Availability disclaimer
9. Inspection action

## Omu Creek

Use only the configured name, land type, title document, per-sqm rate, three approved allocation options, tax disclaimer, and availability qualifier. Do not add a location, amenities, infrastructure, landmarks, plot count, payment plan, extra fees, returns, appreciation, or completion dates.

## Calls to action

Preferred labels include:

- Book an Inspection
- Request an Inspection
- Request an Omu Creek Inspection
- Explore Properties
- View Available Land
- Chat on WhatsApp
- Call an Agent
- Speak With an Adviser
- Discuss a Construction Project
- Discuss Property Management

Use specific actions instead of “Click Here” or repeated “Learn More.”

## SEO

- Use one descriptive H1.
- Write unique titles and descriptions from verified content.
- Mention operating locations only when confirmed.
- Avoid keyword stuffing.
- Add structured data only when the data supports it accurately.
- Do not fabricate review, offer, product, or property schema.
