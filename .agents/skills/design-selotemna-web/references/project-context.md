# Selotemna Project Context

## Brand

Selotemna is a Nigerian corporate real-estate company. The public website helps individuals, families, investors, diaspora customers, and businesses understand its property services and take a credible next step.

The supplied logo displays RC 7361086.

## Public services

Use this list consistently:

1. Property Development
2. Land Sales
3. House Sales
4. Property Management
5. Construction

Do not add a service or detailed operational promise without verification.

## Homepage objective

The homepage should establish corporate credibility, explain the five services, feature Omu Creek, make inspection requests primary, render verified contact actions conditionally, and address diaspora customers without promising unverified remote processes.

## Verified Omu Creek facts

- Name: Omu Creek
- Type: Land allocation
- Title: Certificate of Occupancy (C of O)
- Rate: ₦50,000 per sqm
- 300 sqm: ₦15,000,000
- 500 sqm: ₦25,000,000
- 1,000 sqm: ₦50,000,000
- Prices exclude applicable taxes.
- Availability and property information are subject to confirmation.

Do not infer a location, amenities, infrastructure, landmarks, plot count, allocation schedule, extra fees, payment plans, returns, appreciation, or completion dates.

## Technical baseline

- Laravel 13
- PHP 8.3 or newer
- Blade
- Tailwind CSS v4
- Vite
- Sora headings and Manrope body/interface type
- Minimal framework-free JavaScript

Do not introduce a client-side application framework for the homepage unless the repository has materially changed and the requirement justifies it.

## Brand assets

The active supplied logo is public/assets/logo.png. It is a low-resolution raster asset, so request a transparent SVG or higher-resolution transparent PNG before launch-quality delivery. Do not modify or reconstruct it.

## Content truth

There is no verified catalogue, testimonial set, statistics, operating-location list, or complete contact information. Hide missing content or use silent decorative brand surfaces. Never expose planning notes to visitors.

## Inspection principle

The frontend may identify property interest with stable data attributes. The inspection database workflow is a separate scope. A request must never imply automatic appointment confirmation.
